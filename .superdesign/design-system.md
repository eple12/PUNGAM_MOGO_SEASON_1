# 풍암 실수킬러 모의고사 · 디자인 시스템

## 제품 개요
- 고등학생 대상 수학 모의고사 웹앱(정적 HTML/CSS/JS, 프레임워크 없음, 컴포넌트 라이브러리 없음).
- "제1회 풍암 실수킬러 모의고사" — 수학 영역 대수. 서로 다른 출제자 6인이 5문항씩 맡은
  Day 01~06 여섯 개 회차로 나뉘어 있고, 학생이 원하는 순서로 골라 응시한다(각 회차 30분).
- 지금 개편 대상은 **랜딩(첫) 화면**(`index.html`의 `#screenIntro` / `.rlanding`,
  스타일은 `css/rounds.css`) — 학생이 접속했을 때 가장 먼저 보는 화면이다.
  목표: 학생들의 시선을 사로잡고 "해보고 싶다"는 동기를 주는 랜딩으로 개편.
- 실제 사용 기기: 학교/학원에서 태블릿(아이패드)·노트북·휴대폰 등 다양한 화면.
  펜/터치 필기가 핵심 기능이라 태블릿 비중이 높지만, 랜딩 화면 자체는 텍스트 위주라
  모바일 대응이 중요하다.

## 톤 & 무드
- 대상은 수능/모의고사를 준비하는 한국 고등학생. 과하게 유치하거나 캐주얼하면 신뢰가
  떨어지고, 반대로 관공서 문서처럼 딱딱하면 흥미가 안 생긴다.
- "정식 시험지"의 격식(고사장 분위기, 신뢰감)과 "도전해보고 싶은" 게임적 동기부여
  (Day 01~06를 수집하듯 깨나가는 느낌, 배지/카드 컬렉션) 사이의 균형.
- 기존 화면은 절제된 남색(navy) 톤 + 각 Day 별 은은한 포인트 컬러 6종으로 이미
  "고급스럽고 차분한" 방향을 잡아 두었다. 이 톤 자체는 유지하되, 임팩트·리듬·시선
  유도가 부족해 밋밋해 보이는 게 문제.

## 타이포그래피
```
--font:'Pretendard Variable',Pretendard,-apple-system,BlinkMacSystemFont,
       'Apple SD Gothic Neo','Noto Sans KR','Malgun Gothic','Segoe UI',Roboto,sans-serif;
/* 시험지 제목 계열(평가원 문제지 느낌의 명조체) — 랜딩 타이틀에 이미 사용 중,
   "정식 시험" 무게감을 주는 핵심 요소이므로 유지 */
```

## 제약 사항
- **디자인 시스템에 정의된 색상·폰트·간격만 사용한다. 여기 없는 새로운 색이나
  폰트를 임의로 도입하지 않는다.** 특히 6개 Day 컬러와 navy 메인 컬러, 명조
  타이틀 폰트(--font-exam)는 앱 전체(회차 선택 카드, 시험 화면 등)와 이어지는
  정체성이므로 랜딩만 다른 색 체계로 튀지 않게 한다.
- 실제 사용자는 성인이 아니라 고등학생 — 과장된 이모지·인포머셜 톤은 피하고,
  "이 시험, 꽤 진지하게 준비했구나" 싶은 신뢰감과 "한번 풀어보고 싶다"는 동기
  부여를 동시에 주는 쪽으로.
- 접속 시 첫 화면이므로 로딩 즉시 임팩트가 있어야 한다(설명문을 다 읽어야
  매력이 느껴지는 구조는 피할 것).
